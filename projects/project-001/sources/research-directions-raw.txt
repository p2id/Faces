===EVIDENCE_MD===
Evidence summary: durable product interfaces benefit from visible hierarchy, stable orientation, concise labels, predictable state changes, progressive disclosure, and task-focused feedback. Neutral tonal systems reduce visual competition, while one restrained accent supports emphasis. Responsive quality improves when secondary content collapses before primary actions and reading order remains stable. Accessibility quality improves through semantic structure, keyboard parity, visible focus, contrast, non-color status cues, scalable type, and reduced-motion support. Planning workspace ranks highest because it exercises the widest reusable set of navigation, prioritization, status, comparison, and responsive patterns.

===DIRECTION_A===
Positioning: calm command center for prioritizing information and next actions.
Palette rationale: warm white, graphite, soft gray, and muted blue create focus without urgency.
Type rationale: neutral sans-serif with clear numeric forms supports scanning, hierarchy, and compact metadata.
Layout rules: use a responsive two-region frame; keep primary context persistent; group content into ordered modules; expose detail progressively.
Motion intent: use short fades and position shifts for state changes; preserve spatial continuity; honor reduced-motion preferences.
Avoided traps: dense control walls, competing accents, deep nesting, persistent overlays, decorative motion, and hidden critical actions.

===DIRECTION_B===
Positioning: modular overview for comparing relationships, categories, and status.
Palette rationale: cool gray with muted teal and amber status tones provides separation without visual noise.
Type rationale: high-legibility sans-serif with clear weight contrast distinguishes labels, values, and supporting text.
Layout rules: use an adaptable card grid with consistent alignment; reserve wide modules for summaries; collapse secondary modules before primary content.
Motion intent: use subtle transitions between overview and detail; animate only changed regions and status updates.
Avoided traps: card fragmentation, equal emphasis everywhere, color-only meaning, excessive rounding, and unstable reflow.

===DIRECTION_C===
Positioning: focused sequential workspace for completing one priority at a time.
Palette rationale: deep charcoal text on pale neutral surfaces with a restrained violet accent supports concentration and progression.
Type rationale: reading-optimized sans-serif proportions support extended text while a compact weight scale preserves task hierarchy.
Layout rules: use one dominant column with an optional supporting rail; keep actions near relevant content; separate stages with clear landmarks.
Motion intent: use restrained slide and reveal transitions to explain progression; avoid auto-advancing content and preserve position on return.
Avoided traps: tunnel navigation, hidden context, oversized hero areas, mandatory linearity, and state-dependent action movement.

===DIRECTION_SELECTION===
Chosen direction: A.
Rationale: it offers the strongest balance of reuse, orientation, responsive behavior, accessibility, and low cognitive load for a generic product experience.
Secondary direction: B for comparison, categorization, or status visibility.
Guardrails: retain neutral styling, semantic hierarchy, keyboard parity, visible focus, non-color status cues, scalable type, and reduced-motion support.
