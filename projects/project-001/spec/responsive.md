Breakpoints:
- Compact: 0–599px
- Medium: 600–1023px
- Expanded: 1024px and above
- Wide enhancement: 1440px and above

Rules:
- Use a single-column layout below 600px.
- Stack secondary content below primary content on compact screens.
- Convert persistent navigation to a compact menu at 1023px and below.
- Keep primary actions visible near the task completion area; use a bottom action region on compact screens when needed.
- Use fluid container width with 16px compact padding, 24px medium padding, and 32px expanded padding.
- Allow headings and labels to wrap; never truncate required meaning.
- Use horizontally scrollable data regions only when reflow is not meaningful.
- Maintain minimum 44px touch targets on touch layouts.
- Preserve reading order and keyboard order across layout changes.
- Reduce decorative spacing before reducing content clarity.
- Support zoom to 200% without loss of function.
