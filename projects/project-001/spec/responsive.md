Breakpoints:
- xs: 0–479px
- sm: 480–767px
- md: 768–1023px
- lg: 1024–1439px
- xl: 1440px and above

Rules:
- xs: single column, 16px padding, stacked panels, full-width primary action.
- sm: single column, 20px padding, inline secondary action when space permits.
- md: optional two-column layout, 24px gap, persistent context panel.
- lg: centered container up to 1200px, 32px outer padding, split review layout.
- xl: container capped at 1280px; add whitespace without enlarging controls.
- Preserve reading order and core actions at every width.
- Maintain 44×44px minimum interactive targets.
- Convert tables to labeled rows when horizontal space is insufficient.
- Wrap before truncating; provide full accessible names for truncated text.
- Dialogs are near-full width below md and capped above md.
- Collapse navigation before content becomes cramped.
- Reduce or remove motion when reduced-motion is enabled.
