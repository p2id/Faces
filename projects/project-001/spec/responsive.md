Breakpoints:
- xs: 0–479px.
- sm: 480–767px.
- md: 768–1023px.
- lg: 1024–1439px.
- xl: 1440px and above.

Rules:
- Container max width: 1200px; side padding: 16px xs/sm, 24px md, 32px lg/xl.
- xs/sm: collapse navigation, stack actions, use full-width controls, convert tables to labeled cards, place primary action first.
- md: permit two-column detail layouts when content permits; retain compact navigation.
- lg/xl: show persistent navigation; use split detail layout and optional contextual side panel.
- Grid: 1 column xs/sm, 2 columns md, 3–4 columns lg/xl when content permits.
- Reduce heading scale below md; never reduce body text below 14px.
- Maintain 44px minimum interactive target on touch-capable layouts.
- Preserve reading order and essential content at every width.
- Use horizontal scrolling only for data that cannot reflow meaningfully.
- Respect reduced motion, forced colors, and increased text size.
