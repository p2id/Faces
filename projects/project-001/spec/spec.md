Title: Generic Product Experience
Date: 2026-11-14
Project: project-001
Purpose: Neutral interface for reviewing, organizing, and updating structured product content.

Surfaces:
- Workspace: header, navigation, main content, contextual actions.
- Collection: heading, filters, sorting, result list, pagination.
- Detail: summary, editable fields, properties, related content.
- Feedback: loading, empty, validation, success, warning, and error messages.

Sections:
- Header: “Product workspace”; action: “Save changes”.
- Navigation: “Overview”, “Items”, “Activity”, “Settings”.
- Collection: “Items”, “12 results”, “Filter”, “Sort by relevance”.
- Detail: “Summary”, “Description”, “Properties”, “Last updated”.
- Empty: “No items match these filters.”; action: “Clear filters”.
- Success: “Changes saved.”
- Validation: “Enter a valid value.”
- Error: “Content could not be loaded.”; action: “Try again”.

Content rules:
- Use concise sentence-case labels and explicit action verbs.
- Keep one primary action per surface.
- Use neutral examples: “Sample item”, “Draft description”, “Category”.
- Do not use placeholder text as a label.
- Preserve context between collection and detail surfaces.
