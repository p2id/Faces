Positioning:
A calm command surface for prioritizing important items with minimal visual noise.

Palette rationale:
Warm neutral surfaces, charcoal text, and a muted blue accent create clear hierarchy without visual intensity.

Type rationale:
Neutral sans serif with clear numerals, compact labels, moderate line height, and distinct heading weights supports fast scanning.

Layout rules:
Place context first, summary second, grouped cards third, and one primary action per region. Use a 12-column wide layout and stacked mobile sections.

Motion intent:
Use brief fades and small positional transitions for updates; preserve immediate access and honor reduced-motion preferences.

Avoided traps:
No dashboard clutter, competing primary actions, color-only status, hidden labels, decorative hero content, or essential content behind motion.
