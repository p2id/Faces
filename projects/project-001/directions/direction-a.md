Positioning: Calm operational clarity for dense status and metric review.
Palette rationale: Warm white and graphite surfaces with slate text, blue actions, amber warnings, and red critical states; labels and icons carry meaning alongside color.
Type rationale: Neutral sans-serif with tabular numerals, clear weight contrast, compact headings, and 1.2–1.5 line height.
Layout rules: Persistent wide-screen navigation; metric strip above a summary/detail workspace; 8px grid; maximum content width 1440px; stacked panels below medium widths.
Motion intent: 120–180ms transitions for panel changes and state updates; no looping motion; reduced-motion mode removes nonessential transitions.
Avoided traps: Dashboard clutter, oversized charts, color-only alerts, hidden filters, decorative cards, and irreversible single-step actions.
