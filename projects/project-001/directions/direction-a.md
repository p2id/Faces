POSITIONING
Quiet editorial library prioritizing retrieval, comprehension, and durable context.

PALETTE RATIONALE
Warm off-white surfaces, charcoal text, muted slate borders, and one deep blue accent create focus without visual noise. Semantic colors remain reserved for state.

TYPE RATIONALE
Use a legible sans-serif system with distinct display, heading, body, and metadata scales. Moderate line height supports sustained scanning.

LAYOUT RULES
Use a centered max-width frame, persistent primary navigation, compact secondary navigation, readable content measure, and optional supporting rail. Collapse the rail before reducing content width.

MOTION INTENT
Use 150–220ms fades and position shifts for navigation, filtering, and expansion. Respect reduced-motion preferences and avoid continuous animation.

AVOIDED TRAPS
No ornamental hero imagery, oversized headers, nested modals, tiny metadata, hover-only actions, or excessive card segmentation.
