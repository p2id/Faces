POSITIONING
Focused analysis workspace for comparison, inspection, and deliberate decisions.
PALETTE RATIONALE
Cool gray foundation, deep navy text, pale blue selection states, violet active-context accent, and independent semantic colors.
TYPE RATIONALE
Readable sans-serif with generous line height, clear numerals, and differentiated display and utility sizes.
LAYOUT RULES
Two-pane comparison on wide screens; ordered sections on narrow screens; filters beside affected content; preserve selected context during navigation.
MOTION INTENT
Use restrained pane transitions, filter feedback, and focus movement for spatial orientation; avoid parallax and looping animation.
AVOIDED TRAPS
Excessive side panels, hidden filter state, tiny chart labels, ambiguous selection, deep navigation stacks, and accent color used as status.
