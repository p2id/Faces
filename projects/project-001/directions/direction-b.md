Name: Structured Current
Positioning: A systematic, high-density workspace for comparing priorities, states, and recent changes.
Palette rationale: Cool gray surfaces, graphite text, muted teal accent, and reserved amber or red for semantic exceptions reinforce precision.
Type rationale: Sans-serif with tabular numerals improves alignment across metrics, rows, and timestamps.
Layout rules: Compact header with search and scope controls; resizable canvas; optional comparison rail; grouped rows; clear separators; stacked labeled fields on narrow screens.
Motion intent: Subtle row highlights, filter transitions, and panel resizing communicate state without distraction.
Avoided traps: Microcopy that is too small, ungrouped tables, ambiguous icons, unexpected context changes, hover-only information, and looping motion.
