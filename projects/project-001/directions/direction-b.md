POSITIONING
Structured control surface prioritizing fast scanning, filtering, comparison, and explicit state.

PALETTE RATIONALE
Cool neutral surfaces, dark text, and a saturated teal accent support operational clarity. Tinted status backgrounds appear only when they communicate state.

TYPE RATIONALE
Use compact sans-serif text with tabular numerals for counts and dates. Maintain strong contrast between labels, values, and supporting detail.

LAYOUT RULES
Use a responsive grid with toolbar, filter row, primary content region, and optional detail panel. Preserve table-to-list conversion on narrow screens.

MOTION INTENT
Use 120–180ms transitions for filtering, sorting, panel opening, and confirmation. Avoid movement that changes reading order unexpectedly.

AVOIDED TRAPS
No dashboard clutter, equal-weight tiles, hidden filter logic, color-only categories, dense ungrouped tables, or persistent notification noise.
