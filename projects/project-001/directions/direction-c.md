Name: Open Shelf
Positioning: A neutral content library optimized for discovery, orientation, and return access.
Palette rationale: Soft stone canvas, charcoal text, desaturated teal accent, and quiet surface tints provide warmth without visual noise.
Type rationale: Neutral sans-serif with generous line height and differentiated scale supports titles, summaries, breadcrumbs, and metadata.
Layout rules: Broad search entry, grouped topics, compact result cards, breadcrumbs, predictable detail pages, one-column mobile flow with persistent search access.
Motion intent: Gentle 200ms fades and positional transitions; loading placeholders mirror final geometry; reduced motion removes nonessential transitions.
Avoided traps: Carousel dependency, autoplay, oversized promotional blocks, decorative mascots, vague calls to action, low-information card grids.
