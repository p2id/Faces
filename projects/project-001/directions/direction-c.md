Name: Layered Focus
Positioning: A progressive overview that reveals detail while keeping scope and next action visible.
Palette rationale: Light neutral base, deep ink text, soft lavender accent, and explicit semantic tokens provide restrained distinction.
Type rationale: Sans-serif with clear display-to-body scale and limited emphasis supports overview-to-detail transitions.
Layout rules: Context header; priority modules; expandable secondary sections; persistent filter summary; full-width narrow-screen detail flow; action placed near relevant content.
Motion intent: Brief, interruptible expand, collapse, and crossfade transitions establish hierarchy; all nonessential motion can be removed.
Avoided traps: Hidden information architecture, accordion-only critical content, excessive rounded containers, decorative illustration dependency, and irreversible actions without confirmation.
