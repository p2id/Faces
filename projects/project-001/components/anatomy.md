# Anatomy and Composition
- Page shell: navigation, header, main region, optional detail region, footer.
- Header: title, description, contextual actions; compact layouts collapse secondary actions.
- Toolbar: search, filters, sort, primary action; wrapping preserves logical order.
- Collection: stable heading, count or summary, items, row actions, pagination, feedback.
- Detail: heading, status, grouped attributes, editable controls, action footer.
- Feedback: inline errors beside controls; toast for non-blocking outcomes; dialog for confirmation or focused completion.
- Variants: table/list/cards; inline/drawer/dialog detail; comfortable/compact density without reducing target size.
- States: loading reserves space; empty explains condition and next action; error explains impact and recovery; selected uses color plus border, text, or icon.
- Usage: compose from shared contracts, maintain one dominant task per surface, progressively disclose secondary information.
- Anti-patterns: unbounded layout, nested scrolling, hidden focus, icon-only essential actions, placeholder-as-label, modal overload, color-only status.
- Accessibility: logical heading hierarchy, named landmarks where needed, visual order matching reading order, visible focus, contained transient focus, focus restoration, state changes perceivable without color, motion, or hover.
