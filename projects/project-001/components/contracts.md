# Component Contracts
- Button: anatomy=label, optional icon, progress indicator; variants=primary, secondary, quiet, danger; states=default, hover, focus-visible, pressed, disabled, loading; usage=one dominant action per region; anti-patterns=ambiguous label, unlabeled icon, insufficient disabled contrast; accessibility=native button, visible focus, status for loading.
- Input: anatomy=label, control, hint, error, optional icon; variants=text, search, numeric, multiline; states=empty, filled, focused, disabled, read-only, error, success; usage=persistent label and local guidance; anti-patterns=placeholder-only label, cleared value after error, color-only validation; accessibility=programmatic label, description, autocomplete, error association.
- Select: anatomy=label, trigger, value, indicator, menu, option; variants=single, multi; states=closed, open, selected, disabled, error; usage=bounded choices with current value; anti-patterns=keyboard-incomplete custom menu, hidden selection; accessibility=expanded, controls, selected, and option semantics.
- Checkbox/switch: anatomy=control, label, description; variants=checkbox, switch; states=unchecked/off, checked/on, mixed, focused, disabled, error; usage=independent choice versus immediate binary setting; anti-patterns=unlabeled control, switch for required submission choice; accessibility=name, state, group label, non-color indication.
- Dialog/drawer: anatomy=heading, body, close, action region, progress; variants=confirmation, form, detail; states=closed, opening, open, submitting, error, closing; usage=focused, bounded task; anti-patterns=nested surfaces, lost focus, dismissal-only destructive action; accessibility=labelled modal, focus containment, Escape, restoration.
- Toast: anatomy=message, status icon, optional action, dismiss; variants=success, info, warning, error; states=entering, visible, dismissed; usage=non-blocking outcome; anti-patterns=essential content only in transient message; accessibility=appropriate live-region role and dismissal.
- Collection: anatomy=heading, toolbar, headers/items, rows, pagination, empty/error area; variants=table, list, cards; states=loading, populated, selected, empty, filtered-empty, error; usage=stable labels and predictable actions; anti-patterns=excessive columns, truncated essential data, hover-only actions; accessibility=semantic structure, selection state, responsive alternative.
